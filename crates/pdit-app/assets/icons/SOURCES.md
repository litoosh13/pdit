# Icon sources

All of pdit's interface icons are **Devigner Icons** (D-062; `@devigner-ui/icons` 3.3.0, https://icons.devigner.cc),
Outline variant, rendered unmodified from the package's own components by `web/gooey-island/scripts/export-icons.mjs`
into `devigner/`. Code MIT; artwork derived from the Solar Icon Set by 480 Design (CC BY 4.0) and Iconsax by Vuesax
(free use), modified by Devigner — credited in THIRD_PARTY_NOTICES.md / licenses/other.md. Used as pdit's own
interface icons only, never as user-insertable stamps. Picks approved by the user 2026-10-08
(`.claude/research/icons-d062/`, private). The Koboyo icons used before D-062 were deleted the same day.
