# Caladea

Metric-compatible with Cambria. Used as look-alike fallbacks when a PDF's own font cannot show typed text (D-028). They are fetched only when needed, and only the glyphs used are embedded in the PDF (subset).

- From https://github.com/google/fonts/tree/main/ofl/caladea, downloaded 2026-09-19, files unmodified.
